# MoveUp 🚀

> Move your body, Improve your mind.

MoveUp is a youth activity platform designed to encourage physical activity,
well-being, and personal growth through challenges and gamification.

## 🎯 About the Project

The idea behind MoveUp is to transform small daily actions into challenges
that encourage young people to develop healthier and more active habits.

Users will be able to complete missions, earn XP, level up, and track their
progress.

## ✨ Current Features

- Landing page
- Mission cards
- XP system
- Progress bar
- Level system (in development)
- Daily activity challenges (in development)
